This page documents every key in the `Settings` model (`base/src/platform_network/config/settings.py`). All keys live under a section (for example `master.proxy_port`). See [Configuration](/reference/configuration) for how files and environment variables are merged.

## Top level

| Key | Type | Default | Source |
|-----|------|---------|--------|
| `environment` | string | `development` | `base/src/platform_network/config/settings.py:119` |

The `environment` value drives the [production policy](/reference/configuration#production-policy) when set to `prod`, `production`, or `staging`.

</Tip>
