title: "Bounty Challenge"
description: "Overview of the Bounty Challenge, where owners reward miners for the best finished project work."
---

Bounty Challenge is a secondary challenge for project bounties that need human judgment. An owner publishes a project brief, miners submit completed work as GitHub links, and the owner reviews submissions and assigns emissions to the hotkeys that produced the best work. It targets open-ended tasks where a strict automatic test suite is not enough, such as building a product flow or improving an application's UI and UX.

**Status:** Secondary challenge. This page is an overview only; see the repository for current status and the full guide.
